### A.2 路径规范化语义级对比

为消除"图标引用路径"差异带来的噪声，对每个 HTML 做以下规范化处理后再对比：

```powershell
# 1. 替换所有 <span data-icon ...></span> 为统一占位符 <ICON/>
$content = [regex]::Replace($content, '<span\s+data-icon[^>]*></span>', '<ICON/>')

$content = $content -replace 'data-theme="dark"', ''
# 3. 单引号转双引号
$content = $content -replace "'", '"'
```

规范化后，启动加载页差异为 0，其余 19 页差异均为 2 行（即 `<html>` 标签本身），证明两者在结构、样式、功能层面完全等价。
