## 三、新发现并修复的构建环境问题

### 问题 1: DecisionCard.tsx TypeScript 编译错误
- **错误**: 
  - `PlayCircleOutlined` 未导入但被引用（STATUS_CONFIG.executed 图标）
  - `card.rollbackCommand` (string | undefined) 传给 `navigator.clipboard.writeText()`
- **修复**:
  - 重新添加 `PlayCircleOutlined` 到 imports
  - 改用已有的 `handleCopy` 函数（带成功提示，且闭包内类型自动收窄）

### 问题 2: zod 3.25.0 npm 包 dist 目录缺失
- **错误**: `Error [ERR_PACKAGE_PATH_NOT_EXPORTED]: Package subpath './v3' is not defined by "exports" in zod@3.23.8`
- **根因分析**:
  1. `@modelcontextprotocol/sdk@1.29.0` 要求 `zod ^3.25 || ^4.0`（peer + direct dep）
  2. 之前为规避 zod 3.25.0 dist missing 降级到 3.23.8，但不满足 MCP SDK 要求
  3. zod 3.25.0 的 npm 包**确实只有 src/ 没有 dist/**（发布缺陷，无 postinstall 脚本）
  4. zod 3.25.76（3.25.x 最新）已修复，dist 完整
- **修复**: `pnpm add zod@3.25.76 --save-exact`（package.json: `"zod": "^3.25.76"`）

### 问题 3: ESM/CJS 互操作失败（nanoid@5.x）
- **错误**: `Error [ERR_REQUIRE_ESM]: require() of ES Module nanoid@5.1.16/on-secure/index.js from @ai-sdk/provider-utils/dist/index.js not supported`
- **根因分析**:
  1. `electron-vite` 的 `externalizeDepsPlugin()` 默认将所有 dependencies 标记为 external
  2. `@ai-sdk/openai`、`ai`、`@modelcontextprotocol/sdk` 是 ESM-only 包
  3. 它们在运行时被 Electron main 进程（CJS）`require()` 加载，但内部依赖了 ESM-only 的 `nanoid@5.x`
  4. Electron 30 (Node.js 20) 的 CJS 不支持 `require()` ESM 模块
- **修复**: `electron.vite.config.ts` 中 `externalizeDepsPlugin` 添加 `exclude` 列表，让 vite 打包这些 ESM 包以处理互操作：
  ```typescript
  externalizeDepsPlugin({
    exclude: [
      'ai',
      '@ai-sdk/openai',
      '@modelcontextprotocol/sdk',
      '@volcengine/ark-runtime'
    ]
  })
  ```
- **效果**: main bundle 从 128KB 增至 486KB（343 modules），ESM 互操作由 vite 处理
