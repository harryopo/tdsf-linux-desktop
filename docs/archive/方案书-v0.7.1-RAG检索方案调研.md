## 1. 调研背景与约束

### 1.1 场景

- **数据规模**：2578 条教程，分 15 个分类（`/src/main/services/tutorial/` 已有数据）
- **检索需求**：用户用自然语言搜索"如何配置 SSH 密钥登录？"→ 返回最相关 5-10 条教程
- **混合需求**：既要 BM25 关键词命中（命令名 / 参数），也要向量语义命中（"配置 SSH"≈"密钥认证"）
- **运行环境**：Electron 桌面应用（`tdsf-linux-desktop@0.9.0`），主进程 + 渲染进程
- **现有依赖**：`better-sqlite3@^12.11.0` + `@photostructure/sqlite-vec@^1.2.0`（已装！）

### 1.2 硬约束

1. **本地优先**：默认离线可用，敏感数据不出端
2. **零运维**：不开 Docker / 不起服务进程 / 不引入 Python 运行时
3. **国内网络**：避免 GitHub release 直连失败，优先 npm registry（已用 npmmirror 镜像）
4. **License 安全**：严禁引入 AGPL / SSPL / BSL 1.1 等限制商用或传染性 License
5. **质量绝对优先**（用户偏好）：不允许为节省资源而跳步 / 降级

### 1.3 软约束

- 单条入库延迟 < 100ms（Electron 主进程不卡 UI）
- 检索 p95 < 200ms（2578 条规模）
- embedding 维度 ≤ 1024（sqlite-vec 友好，< 4096 上限）
- 支持中文（教学场景主力语言）

### 2.2 逐项关键发现

#### ① sqlite-vec ⭐ 7.3k（**最适合本项目**）

- **状态**：pre-v1（v0.1.10-alpha），但 Mozilla 官方已 vendor 进 Firefox ([moz.yaml](http://raw.githubusercontent.com/mozilla-firefox/firefox/main/third_party/sqlite3/ext/sqlite-vec/moz.yaml))，稳定性有保障
- **维护方**：Alex Garcia (asg017)，Mozilla Builders 赞助 + Fly.io / Turso
- **生产 fork**：`@photostructure/sqlite-vec@1.2.0`（PhotoStructure Inc. 维护），已装在项目 `package.json`
- **协议**：MIT + Apache-2.0 双协议，**完全无传染风险**
- **性能**：在 10 万级向量规模下亚百毫秒延迟（[CSDN 2026-07-13 测评](https://blog.csdn.net/lonelymanontheway/article/details/162846678)）；2578 条规模下**预计 < 5ms**
- **优势**：
  - 纯 C，单二进制几百 KB
  - 跨平台（Linux/macOS/Windows/WASM/iOS/Android/RPi）
  - `vec0` 虚拟表支持 KNN + 元数据过滤 + 分区键
  - 与 better-sqlite3 无缝集成
- **风险**：
  - v0.1.x 仍可能有破坏性变更（pre-v1 阶段）
  - 当前默认 KNN 是**暴力穷举**，>10 万向量需 HNSW 实验功能
  - Electron 需在 `electron-builder` 配置 `asarUnpack` 解压 `.so` / `.dll`

#### ② LanceDB ⭐ ~16-18k

- **状态**：v0.x → 1.0 阶段，**Apache-2.0**，Series A 融资 $30M（[aiwiki](https://aiwiki.ai/wiki/lancedb)）
- **优势**：Lance 列存格式 + IVFPQ 索引，多模态（text+image+video），**自带 BM25 全文搜索**
- **劣势**：
  - 主要面向 Python / TypeScript 生态，**Rust SDK 较新**
  - Electron 集成需 npm 引入 `@lancedb/lancedb`（约 30MB）
  - 本地模式下依赖 Arrow + native 绑定，**首次初始化慢**
- **适配度**：⭐⭐⭐（适合 1 万+ 向量规模，2578 条杀鸡用牛刀）

#### ③ Chroma ⭐ 27-28.5k

- **状态**：Apache-2.0，v1.3.3 稳定，每周发版
- **优势**：
  - 4 个 API 即可上手（`create_collection / add / query / get`）
  - 自动 tokenize + embedding（自带 BGE / ONNX 模型）
  - 自带 **BM25 / SPLADE** 全文搜索
- **劣势**：
  - **生产部署需启动独立服务**（`chroma run --path ...`）
  - 2578 条规模下资源占用偏大（Python 进程 + Rust 引擎）
  - 团队是 Python 优先，Node 客户端是次等公民
- **适配度**：⭐⭐（适合 Python 后端 / 服务化场景，**不适合 Electron 桌面端**）

#### ④ Qdrant ⭐ 22-30k

- **状态**：Apache-2.0，v1.18.3（2026-07-17 刚发）
- **优势**：Rust 性能最强，**HNSW 索引成熟**，混合检索（dense + sparse + BM25）原生支持
- **劣势**：
  - **必须起独立服务**（Docker / 二进制 / K8s）
  - REST + gRPC 双协议，Electron 主进程需 HTTP 调用 → 引入 IPC 延迟
  - 2578 条规模性能严重过剩
- **适配度**：⭐⭐（适合 10 万+ 规模 / 服务化场景）

#### ⑤ Milvus ⭐ 45.2k

- **状态**：LF AI & Data Foundation 毕业项目，Apache-2.0，v2.6.19（2026-07-20 刚发）
- **优势**：分布式架构 + GPU 加速 + DiskANN，**亿级向量成熟方案**
- **劣势**：

  - 12K+ Docker pulls/天，**企业级定位**
  - 2578 条规模性能严重过剩
- **适配度**：⭐⭐（适合 GraphQL 体系团队）

#### ⑧ pgvector ⭐ 20.5-22.2k

### 5.2 数据库初始化（src/main/services/tutorial/tutorial-repo.ts）

```typescript
import Database from 'better-sqlite3'
import * as sqliteVec from '@photostructure/sqlite-vec'
import { app } from 'electron'
import { join } from 'path'

export class TutorialRepository {
  private db: Database.Database

  constructor() {
    const dbPath = join(app.getPath('userData'), 'tutorials.db')
    this.db = new Database(dbPath)

    // 1. 加载 sqlite-vec 扩展（核心依赖！）
    // 解释：@photostructure/sqlite-vec 是 asg017/sqlite-vec 的生产 fork
    // 跨平台预编译，无需后编译
    sqliteVec.load(this.db)

    // 2. 启用 WAL 模式（提升并发读 + 单写性能）
    this.db.pragma('journal_mode = WAL')
    this.db.pragma('synchronous = NORMAL')

    // 3. 主表（教程原文）
    this.db.exec(`
      CREATE TABLE IF NOT EXISTS tutorials (
        id INTEGER PRIMARY KEY,
        title TEXT NOT NULL,
        content TEXT NOT NULL,
        category TEXT NOT NULL,
        tags TEXT,
        difficulty INTEGER DEFAULT 1,
        source TEXT,
        created_at INTEGER DEFAULT (strftime('%s', 'now')),
        updated_at INTEGER DEFAULT (strftime('%s', 'now'))
      );
    `)

    // 4. FTS5 虚拟表（BM25 全文检索）
    // 解释：content='tutorials' 表示这是 tutorials 的影子表
    // tokenize='unicode61 remove_diacritics 2' 适配中文
    this.db.exec(`
      CREATE VIRTUAL TABLE IF NOT EXISTS tutorials_fts USING fts5(
        title,
        content,
        tags,
        content='tutorials',
        content_rowid='id',
        tokenize='unicode61 remove_diacritics 2'
      );
    `)

    // 5. vec0 虚拟表（向量 KNN 检索）
    // 解释：embedding float[384] 是 BGE-small-zh-v1.5 维度
    // partition key = category 加速分类过滤
    this.db.exec(`
      CREATE VIRTUAL TABLE IF NOT EXISTS tutorials_vec USING vec0(
        id INTEGER PRIMARY KEY,
        embedding float[384],
        category TEXT PARTITION KEY
      );
    `)

    // 6. 触发器：保证 FTS5 与主表同步
    this.db.exec(`
      CREATE TRIGGER IF NOT EXISTS tutorials_ai AFTER INSERT ON tutorials BEGIN
        INSERT INTO tutorials_fts(rowid, title, content, tags)
        VALUES (new.id, new.title, new.content, new.tags);
        INSERT INTO tutorials_vec(id, embedding, category)
        VALUES (new.id, new.embedding, new.category);
      END;

      CREATE TRIGGER IF NOT EXISTS tutorials_ad AFTER DELETE ON tutorials BEGIN
        DELETE FROM tutorials_fts WHERE rowid = old.id;
        DELETE FROM tutorials_vec WHERE id = old.id;
      END;

      CREATE TRIGGER IF NOT EXISTS tutorials_au AFTER UPDATE ON tutorials BEGIN
        UPDATE tutorials_fts SET
          title = new.title,
          content = new.content,
          tags = new.tags
        WHERE rowid = new.id;
        UPDATE tutorials_vec SET
          embedding = new.embedding,
          category = new.category
        WHERE id = new.id;
      END;
    `)
  }
}
```

### 5.3 Hybrid Search 实现（src/main/services/tutorial/hybrid-search.ts）

```typescript
import type Database from 'better-sqlite3'

export interface HybridResult {
  id: number
  title: string
  content: string
  category: string
  fts_score: number
  vec_score: number
  rrf_score: number
  source: 'fts' | 'vec' | 'both'
}

/**
 * RRF 倒数排名融合算法
 * 公式：score(d) = Σ 1 / (k + rank_i(d))
 * k 通常取 60（Cormack et al. 2009 论文）
 */
export function reciprocalRankFusion(
  results: Map<number, { fts_rank?: number; vec_rank?: number }>,
  k = 60
): Map<number, number> {
  const fused = new Map<number, number>()
  for (const [id, ranks] of results) {
    let score = 0
    if (ranks.fts_rank !== undefined) score += 1 / (k + ranks.fts_rank)
    if (ranks.vec_rank !== undefined) score += 1 / (k + ranks.vec_rank)
    fused.set(id, score)
  }
  return fused
}

export function hybridSearch(
  db: Database.Database,
  query: string,
  queryEmbedding: Float32Array,
  limit = 10,
  weights: { fts: number; vec: number } = { fts: 1.0, vec: 1.0 }
): HybridResult[] {
  // ===== Step 1: FTS5 BM25 检索 =====
  // bm25(fts) 越小越相关（负值），取负号转为正分
  const ftsResults = db
    .prepare(
      `SELECT rowid AS id, bm25(tutorials_fts) AS score
       FROM tutorials_fts
       WHERE tutorials_fts MATCH ?
       ORDER BY score
       LIMIT 50`
    )
    .all(query) as { id: number; score: number }[]

  // ===== Step 2: vec0 KNN 检索 =====
  // sqlite-vec 距离越小越相关，转为相似度 = 1 - distance
  const buf = Buffer.from(queryEmbedding.buffer)
  const vecResults = db
    .prepare(
      `SELECT id, distance
       FROM tutorials_vec
       WHERE embedding MATCH ? AND k = 50
       ORDER BY distance`
    )
    .all(buf) as { id: number; distance: number }[]

  // ===== Step 3: RRF 融合 =====
  const ranks = new Map<number, { fts_rank?: number; vec_rank?: number }>()
  ftsResults.forEach((r, idx) => {
    const existing = ranks.get(r.id) || {}
    ranks.set(r.id, { ...existing, fts_rank: idx + 1 })
  })
  vecResults.forEach((r, idx) => {
    const existing = ranks.get(r.id) || {}
    ranks.set(r.id, { ...existing, vec_rank: idx + 1 })
  })

  const rrfScores = reciprocalRankFusion(ranks)

  // ===== Step 4: 关联主表 + 排序 =====
  const ids = Array.from(rrfScores.keys())
  if (ids.length === 0) return []

  const placeholders = ids.map(() => '?').join(',')
  const tutorials = db
    .prepare(
      `SELECT id, title, content, category, tags
       FROM tutorials
       WHERE id IN (${placeholders})`
    )
    .all(...ids) as Array<{
    id: number
    title: string
    content: string
    category: string
    tags: string
  }>

  const tutorialMap = new Map(tutorials.map((t) => [t.id, t]))

  const results: HybridResult[] = []
  for (const id of ids) {
    const t = tutorialMap.get(id)
    if (!t) continue
    const rrf = rrfScores.get(id) || 0
    results.push({
      id: t.id,
      title: t.title,
      content: t.content,
      category: t.category,
      fts_score: ftsResults.find((r) => r.id === id)?.score ?? 0,
      vec_score: vecResults.find((r) => r.id === id)?.distance ?? 1,
      rrf_score: rrf * (weights.fts + weights.vec) / 2,
      source: ftsResults.find((r) => r.id === id)
        ? vecResults.find((r) => r.id === id)
          ? 'both'
          : 'fts'
        : 'vec',
    })
  }

  return results.sort((a, b) => b.rrf_score - a.rrf_score).slice(0, limit)
}
```

### 6.3 代码示例（src/main/services/ima/ima-client.ts）

```typescript
import { app } from 'electron'
import { safeStorage } from 'electron'

const IMA_BASE = 'https://ima.qq.com'
const IMA_OPENAPI = `${IMA_BASE}/openapi/wiki/v1`

interface ImaConfig {
  clientId: string
  apiKey: string
  knowledgeBaseId: string
}

export class ImaClient {
  private config: ImaConfig

  constructor() {
    // 1. 从 safeStorage 解密凭证（避免明文存储）
    // 解释：safeStorage 用 OS Keychain 加密，Windows = DPAPI
    const encrypted = app.getPath('userData') + '/.ima-creds.enc'
    this.config = this.loadCredentials(encrypted)
  }

  /**
   * 搜索知识库
   * 接口：POST /openapi/wiki/v1/search_knowledge
   * 鉴权：HTTP Header `ima-openapi-clientid` + `ima-openapi-apikey`
   */
  async search(query: string, limit = 10): Promise<unknown[]> {
    const res = await fetch(`${IMA_OPENAPI}/search_knowledge`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'ima-openapi-clientid': this.config.clientId,
        'ima-openapi-apikey': this.config.apiKey,
      },
      body: JSON.stringify({
        query,
        cursor: '',
        knowledge_base_id: this.config.knowledgeBaseId,
        limit,
      }),
    })

    if (!res.ok) {
      // 错误码 200002 = API Key 过期，需引导用户重新获取
      throw new Error(`ima search failed: ${res.status} ${await res.text()}`)
    }

    const data = await res.json()
    return data.data?.items || []
  }

  /**
   * 批量导入教程（用于云端兜底）
   * 注意：单次最多 100 条，2578 条需分 26 批
   */
  async importBatch(tutorials: Array<{ title: string; content: string }>) {
    const BATCH = 100
    for (let i = 0; i < tutorials.length; i += BATCH) {
      const batch = tutorials.slice(i, i + BATCH)
      await fetch(`${IMA_OPENAPI}/import_urls`, {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          'ima-openapi-clientid': this.config.clientId,
          'ima-openapi-apikey': this.config.apiKey,
        },
        body: JSON.stringify({
          knowledge_base_id: this.config.knowledgeBaseId,
          urls: batch.map((t) => `data:text/markdown;base64,${Buffer.from(
            `# ${t.title}\n\n${t.content}`
          ).toString('base64')}`),
        }),
      })
    }
  }
}
```

### 7.1 双源召回架构

```
用户查询 "如何配置 SSH 密钥"
       ↓
   ┌─── 本地 sqlite-vec (Top-10) ───┐
   │                                │
   │  FTS5: "SSH" 命中 6 条         │
   │  vec0: 语义相似 4 条           │

   └────┬───────────────────────────────────────┘

```

### 7.2 关键代码

```typescript
async function hybridSearchWithCloud(
  query: string,
  queryEmbedding: Float32Array,
  cloudEnabled: boolean
): Promise<HybridResult[]> {
  // Step 1: 本地检索（永远执行）
  const localResults = hybridSearch(db, query, queryEmbedding, 10)

  // Step 2: 云端检索（仅在用户开启时 + 网络可用时）
  let cloudResults: HybridResult[] = []
  if (cloudEnabled && navigator.onLine) {
    try {
      const items = await imaClient.search(query, 5)
      cloudResults = items.map((item: any) => ({
        id: `ima:${item.doc_id}`,
        title: item.title,
        content: item.content,
        category: 'ima-cloud',
        fts_score: 0,
        vec_score: item.score,
        rrf_score: 0, // 二次 RRF 时再算
        source: 'vec',
      }))
    } catch (e) {
      // 网络异常 / Key 过期 → 静默降级
      console.warn('[hybrid] cloud search failed, fallback to local', e)
    }
  }

  // Step 3: 二次 RRF 融合（本地 0.7 + 云端 0.3 权重）
  const all = [...localResults, ...cloudResults]
  return reciprocalRankFusionWeighted(all, { local: 0.7, cloud: 0.3 })
}
```
