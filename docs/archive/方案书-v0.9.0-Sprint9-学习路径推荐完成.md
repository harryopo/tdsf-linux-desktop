# 方案书-v0.9.0-Sprint9-学习路径推荐完成

## 1. Sprint 目标

实现学习路径推荐功能，利用现有混合检索基础设施，通过 4 层融合算法为用户推荐个性化 Linux 运维学习路径。

## 2. 核心功能

### 2.1 4 层融合算法

1. **分类依赖图**：linux-basics → user-management → services → troubleshooting
2. **难度递进**：beginner → intermediate → advanced（同分类内）
3. **命令关联**：commands 共现分析（学完 ls → cd → grep）
4. **混合检索召回**：hybridSearch 召回相关教程，按 rrfScore 排序

### 2.2 数据模型

- **PathStep**：学习路径步骤（order / tutorialId / title / category / difficulty / readingTime / commands / why / summary）
- **TutorialPath**：学习路径（id / name / description / targetCategory / targetDifficulty / steps / estimatedMinutes / prerequisites / reason）
- **RecommendPathOptions**：路径推荐请求参数（goal / currentLevel / preferredCategory / maxSteps）

## 3. 实现细节

### 3.1 主进程服务

- **文件**：`src/main/services/tutorial/path-recommender.ts`
- **类**：`PathRecommender`
- **方法**：`recommend(options?: RecommendPathOptions): TutorialPath[]`
- **核心逻辑**：
  - `buildPrerequisitePaths()`：构建前置知识路径
  - `buildCategoryPaths()`：构建同级分类路径
  - `buildCommandAssociationPaths()`：构建命令关联路径
  - `buildHybridSearchPaths()`：构建混合检索路径
  - `fusePaths()`：4 层路径融合

### 3.2 IPC 通道

- **通道名**：`tutorial:recommend-path`
- **主进程**：`src/main/ipc/tutorial.ts`
- **请求参数**：`RecommendPathOptions`
- **返回值**：`TutorialPath[]`

### 3.3 Preload 暴露

- **文件**：`src/preload/index.ts`
- **方法**：`tutorialRecommendPath(options?: RecommendPathOptions): Promise<TutorialPath[]>`
- **类型**：内联定义 `PathStep` / `TutorialPath` / `RecommendPathOptions`

### 3.4 渲染进程 Hook

- **文件**：`src/renderer/src/hooks/useRecommendPath.ts`
- **Hook**：`useRecommendPath(defaultOptions?: UseRecommendPathOptions)`
- **返回值**：`{ paths / loading / error / recommend }`

### 3.5 UI 组件

- **文件**：`src/renderer/src/components/tutorial/v1/LearningPathCard.tsx`
- **组件**：`LearningPathCard`
- **子组件**：`StepItem`
- **功能**：展示完整学习路径（头部信息 / 前置知识 / 推荐理由 / 步骤列表）

### 3.6 TutorialPage 集成

- **文件**：`src/renderer/src/pages/TutorialPage.tsx`
- **集成点**：
  - 引入 `useRecommendPath` Hook
  - 引入 `LearningPathCard` 组件
  - 添加"推荐学习路径"区域
  - "为我推荐"按钮触发路径推荐
  - 展示 loading / error / 路径列表 / 空状态
