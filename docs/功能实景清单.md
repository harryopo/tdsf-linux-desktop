### 命令风险闸

判定只有一个入口：`src/main/core/command-gate.ts:768 evaluateCommand`
（结构性拦截器 8 条在 `:95-104`，argv 规则与词表项由 `scripts/quality/promo-readout.mjs` 现场数）。

命令闸管的四个出口都过闸：

- 远程 exec：`src/main/ipc/ssh.ts:350`
- 交互键入（攒到回车整行判）：`src/main/ipc/ssh.ts:20` 的 LineGate、本机终端同口径 `src/main/ipc/local-terminal.ts:20`
- AI 代写命令：`src/main/services/llm/tools/ssh-exec.ts:17`
- 内置 MCP server 的工具派发：`src/main/services/mcp/server.ts:436` 的 `assessToolCall`

**第五个出口没过闸，这里如实写**：渲染层直连外部 MCP server 的 `mcp:external-call`
（`src/main/ipc/mcp.ts:85` → `src/main/core/agent/mcp-gateway.ts` → 子进程）一路没有闸调用。
当前它不构成实际风险面，因为界面里没有任何入口会调它（`mcpExternalCall` 在渲染层零调用方），
但通道是敞的——一旦给 MCP 配界面，这条必须先接闸。详见 §C 组与 `docs/长期优化目标.md`。

规则本身在界面可读：`src/renderer/src/pages/RiskSettings.tsx:111`（只读快照）。

## C 组 · 断线（有实现、有测试，生产链路零调用）

统计口径：preload 暴露 **274** 个键，其中 **139 个在 `src/renderer` 里零引用**（2026-10-21 实测）。
上一拍记的是 141——`historyBlocks` 上台后刻度没跟着降，本轮把 `storageDeleteApiKey` 接到
「清除已保存的 Key」按钮，两笔一起收进刻度。
现在 `pnpm audit:ipc` 把它钉成只降不升的刻度（`UNUSED_CAP = 139`，CI 里跑）：
新增一个"后端有、前端没人按"的键会直接红；负向对照验过（把刻度改成比实测小 1 立刻 rc=1）。
knip 查不出这一层（它把 preload 当 entry，只看引用不看调用），所以这条数只能靠通道面反查。

下面这些**不要**当成「可用功能」介绍给任何人：

- **Subagent 调度器**：9 个 Subagent 在 `supervisor.ts:338` 被实例化，但 `subagents/dispatcher.ts`
  的 8 步调度只被 `subagents/index.ts` 转出、生产零调用点（只有两个访问器）。
  原先并列的"14 步 Task Protocol"与它那套 `task-sediment` / Task Permission 审批已按下面那条口径
  **整删**（2026-10-20：实现 7 个文件 + `task-permission-approval.ts` + `TASK` 通道 + preload 两把键 +
  5 个测试文件 + `shared/approval-types.ts` 里三个形状），代码只留在 git 历史。
- **旧 AgentWorkflow 与裸 llm 通道**：`ipc/agent.ts` + preload `agentStart/agentConfirm`、`preload/index.ts:138-142` 的 `llmChat` 全家。
- **@命令解析**：`core/agent/at-commands/*` + `ipc/at-commands.ts:125`（Composer 里的 `injectedAtCommand` 是另一套实现，`Composer.tsx:127`）。
- **五模式**：`ipc/mode.ts:92-168` 无 UI；mode-registry 只被上面那条死路径和 `mcp/resources.ts:323` 读。
- **attention 追踪 / expectation 监控 / deploy / promptfoo**：`ipc/attention.ts:78-239`、`ipc/expectation.ts:65`、`ipc/deploy.ts:33-111`、`ipc/promptfoo.ts:36-68`。

  另注：外部工具调用通道 `mcp:external-call`（`ipc/mcp.ts:85`）不带命令闸，见上面"命令风险闸"一节。

  serverExport/Import（原始字符串版；界面上走的是 2026-10-21 新接的 `server:export-file/import-file`）、

## 维护规矩

1. 新能力进这份文档的前提是**有生产调用点**；只有测试引用的写进 C 组，不写进 A 组。
2. 每组结论都要留 `file:line`；行号漂了由 `doc:links` 与代码审查负责抓，不由记忆负责。
3. 数字只有一个出口：`npm run promo:check`。这份文档里出现任何统计值，都要能指回一条命令。
