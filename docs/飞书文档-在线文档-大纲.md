## 1. 产品简介

**TDSF Linux 运维教学一体平台**（TDSF Linux O&M Teaching Integrated Platform）是一款面向 Linux 运维教学的 **IDE + AI 一体化桌面应用**（IDE + AI integrated desktop application）。

### 1.1 核心定位

> **"AI 不是替代运维，而是让运维可解释。"**
> *AI does not replace O&M, but makes O&M explainable.*

### 1.2 四大核心能力

| 能力（Capability） | 说明（Description） | 学习收益（Learning Benefit） |
| --- | --- | --- |
| **SSH 终端**（SSH Terminal） | xterm.js 全屏 Shell + 跳板机（Jump Host） | 掌握真实服务器交互 |
| **AI 助手**（AI Assistant） | LLM 推理 + 证据链（Evidence Chain） | 学习人机协同决策 |
| **可信决策**（Credible Decision） | 4 层风险控制（4-Layer Risk Control） | 培养运维安全意识 |
| **知识库**（Knowledge Base） | 命令手册 + 案例库（Command + Cases） | 沉淀实战经验 |

### 1.3 适用场景

- 🎓 高校 Linux 运维课程教学
- 💼 运维工程师入门培训
- 🏢 中小企业轻量级运维工具
- 🧪 自动化运维实验平台

### 1.4 技术规格

## 2. 快速开始

### 2.1 安装（Installation）

#### Windows
```bash
# 下载安装包（Download installer）
TDSF-Linux-Desktop-Setup-2.4.1.exe

# 或使用便携版（Portable version）
TDSF-Linux-Desktop-Portable-2.4.1.zip
```

#### macOS
```bash
# 下载 dmg 文件
TDSF-Linux-Desktop-2.4.1.dmg
```

#### Linux
```bash
# AppImage
chmod +x TDSF-Linux-Desktop-2.4.1.AppImage
./TDSF-Linux-Desktop-2.4.1.AppImage
```

### 2.2 首次启动（First Launch）

1. 双击图标启动应用
2. 等待启动页加载（首次约 5s）
3. 进入工作台（Workbench）默认页
4. 配置 LLM API Key（设置 → 模型）

### 2.3 连接第一台服务器（Connect Your First Server）

1. 点击左侧 **"+"** → 新建连接
2. 选择认证方式：
   - 密码认证（Password Authentication）
   - 密钥认证（Key Authentication）
3. 输入主机信息：
   - 主机（Host）：`192.168.1.100`
   - 端口（Port）：`22`
   - 用户名（Username）：`root`
4. 点击 **连接（Connect）**
5. 在终端输入 `ls` 验证

## 3. 核心功能

### 3.1 IDE 工作台（IDE Workbench）

基于 `@monaco-editor/react` 的代码编辑器，集成：
- **文件树（File Tree）**：浏览服务器目录
- **SFTP 传输（SFTP Transfer）**：上传/下载文件
- **多标签页（Multi-Tab）**：同时编辑多个文件
- **语法高亮（Syntax Highlighting）**：100+ 语言

### 3.2 AI 对话面板（AI Chat Panel）

支持 5 种交互模式：
1. **直接对话（Direct Chat）**：自然语言提问
2. **@命令注入（@Command Injection）**：`@server`、`@log`、`@metric` 等
3. **Skill 调用（Skill Invocation）**：调用预设技能包
4. **深度思考（Deep Thinking）**：多步推理 + 证据核验
5. **方法论（Methodology）**：查看推理依据

### 3.3 监控面板（Monitor Panel）

- CPU / 内存 / 磁盘 / 网络 实时图表
- 进程列表（Process List）Top 20
- 告警阈值（Alert Threshold）配置

### 3.4 日志系统（Log System）

- Drain3 模板提取（Drain3 Template Mining）
- 多服务器日志聚合（Multi-Server Log Aggregation）
- 异常模式检测（Anomaly Pattern Detection）

### 3.5 决策卡（Decision Card）

AI 给出每条建议时，自动生成：
- 📊 证据链（Evidence Chain）
- 🎯 置信度（Confidence Score，0-1）
- ⚠️ 风险等级（Risk Level：低/中/高/危险）
- 🤖 推理步骤（Reasoning Steps）
- 👤 人工审批（Human Approval）

## 4. SSH 教程

### 4.1 密码认证（Password Auth）

```yaml
认证方式: password
用户名: root
密码: ********
主机: 192.168.1.100
端口: 22
```

### 4.2 密钥认证（Key Auth）— 推荐

```yaml
认证方式: privateKey
用户名: root
私钥路径: C:\Users\xxx\.ssh\id_rsa
密码短语: ******** # 可选（Optional）
主机: 192.168.1.100
端口: 22
```

**生成 SSH 密钥对**：
```bash
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
```

### 4.3 跳板机（Jump Host）

通过跳板机连接内网服务器：
```yaml
跳板机:
  主机: jump.example.com
  端口: 22
  用户名: jumpuser
  认证: 密钥

目标服务器:
  主机: 10.0.0.5
  端口: 22
  用户名: root
```

### 4.4 SFTP 文件管理

支持操作：
- 上传（Upload） / 下载（Download）
- 删除（Delete） / 重命名（Rename）
- 修改权限（chmod）/ 修改属主（chown）

## 6. 可信决策系统

### 6.1 6 大核心机制

1. **证据置信度公式（Confidence Formula）**：`0.7 × Drain3匹配度 + 0.3 × 来源先验`
2. **证据溯源校验（Ground-Check）**：每条证据必须来自真实工具调用
3. **自适应自洽采样（Adaptive Sampling）**：置信度 ≥0.7 单次，<0.7 三次重采样
4. **4 层风险控制（4-Layer Risk Control）**：语法检查 → 风险评估 → 证据展示 → 人工确认
5. **双推理模式（Dual Reasoning）**：快速（简单）/ 深度（多步+证据）
6. **知识双轨制（Dual-Track Knowledge）**：command_skills + incident_cases

### 6.2 风险等级（Risk Levels）

| 等级 | 颜色 | 行为 | 示例 |
| --- | --- | --- | --- |
| 低（Low） | 🟢 绿 | 自动执行 | `ls`、`cat` |
| 中（Medium） | 🟡 黄 | 需 1 次确认 | `systemctl restart nginx` |
| 高（High） | 🟠 橙 | 需 2 次确认 | `rm -rf /var/log/*.log` |
| 危险（Dangerous） | 🔴 红 | 强制阻断 | `rm -rf /`、`mkfs` |

### 6.3 三态权限审批（3-State Permission）

参考 AgentScope Permission 设计：
- **ALWAYS**：自动批准
- **AUTO**：智能判断（低风险自动 / 高风险询问）
- **NEVER**：永不执行

## 9. 常见问题

### Q1：API Key 安全吗？
**A**：使用 Electron safeStorage 加密，存储在 OS 钥匙串（Windows DPAPI / macOS Keychain / Linux libsecret）。

### Q2：AI 回答准确吗？
**A**：所有建议必须通过 Ground-Check 证据验证，置信度 <0.7 触发重采样。高风险操作强制人工审批。

### Q3：是否支持离线使用？
**A**：终端 / 文件管理 / 知识库支持纯离线。AI 功能需要联网（LLM API）。

### Q4：如何贡献代码？
**A**：参见 [GitHub 仓库](https://github.com/your-repo) 提 PR。

**A**：MIT License，可自由使用和修改。
