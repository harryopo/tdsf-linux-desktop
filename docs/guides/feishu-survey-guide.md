# 飞书问卷制作教程

> 火山杯 2026 比赛期间用于收集用户反馈与产品改进建议
> 最终链接嵌入 AboutSettings 的"产品调研问卷"卡片
> 制作时间：2026-07-25

---

## 1. 制作流程总览

```
飞书工作台 → 问卷应用 → 新建问卷 → 设计题目 → 设置权限 → 发布 → 复制链接 → 填入软件
```

预计耗时：30-60 分钟（含题目设计）

---

## 2. 详细步骤

### 2.1 进入飞书工作台

1. 打开浏览器访问 <https://www.feishu.cn/>
2. 登录你的飞书账号（建议用比赛团队账号，便于统一管理）
3. 顶部导航点击 **"工作台"** → 左侧应用列表找到 **"问卷"**（或搜索"问卷"）
4. 如果没看到"问卷"应用，点击 **"应用中心"** 搜索 **"问卷"** 并添加到工作台

### 2.2 新建问卷

1. 进入问卷应用后，点击右上角 **"+"** 或 **"新建问卷"**
2. 选择 **"空白问卷"**（不要选模板，模板字段不灵活）
3. 填写问卷基本信息：
   - **问卷标题**：`TDSF-Linux Desktop 产品反馈（火山杯 2026）`
   - **问卷描述**：`感谢您使用 TDSF-Linux Desktop！您的反馈将帮助我们改进产品，填写约 2 分钟。`

### 2.3 题目设计（推荐 8-12 题，2-3 分钟填完）

#### 模块 A：用户背景（2 题）

**题 1：您的身份**（单选，必填）
- ☐ 计算机相关专业学生
- ☐ Linux 运维工程师
- ☐ 后端 / DevOps 工程师
- ☐ 教师 / 培训讲师
- ☐ 其他：____

**题 2：您的 Linux 使用年限**（单选，必填）
- ☐ 0-6 个月（初学者）
- ☐ 6 个月 - 2 年
- ☐ 2-5 年
- ☐ 5 年以上

#### 模块 B：核心功能体验（3 题，李克特 5 级量表）

**题 3：SSH 终端使用满意度**（单选，必填）
- ☐ 非常不满意
- ☐ 不满意
- ☐ 一般
- ☐ 满意
- ☐ 非常满意

**题 4：高危命令拦截的实用性**（单选，必填）
- ☐ 完全没用
- ☐ 没用
- ☐ 一般
- ☐ 有用
- ☐ 非常有用（救过我命）

**题 5：AI 辅助回答的准确度**（单选，必填）
- ☐ 经常答错
- ☐ 偶尔答对
- ☐ 一般
- ☐ 多数时候答对
- ☐ 非常准确

#### 模块 C：可信度评估（1 题，核心亮点）

**题 6：6 源证据可视化是否有助于判断 AI 建议的可靠性？**（单选，必填）
- ☐ 非常有帮助
- ☐ 有帮助
- ☐ 一般
- ☐ 没什么用
- ☐ 反倒增加认知负担

#### 模块 D：改进建议（2-3 题，开放式）

**题 7：您最希望新增的功能是什么？**（多行文本，选填）

**题 8：使用过程中遇到的最大问题是什么？**（多行文本，选填）

**题 9：其他任何想说的话**（多行文本，选填）

#### 模块 E：联系方式（1 题，可选）

**题 10：是否愿意接受产品功能内测邀请？**（单选，选填）
- ☐ 愿意（请在下方留邮箱/微信）
- ☐ 不愿意
- 邮箱/微信号：____

### 2.4 题目格式小贴士

- **单选题**：适合互斥选项（背景类）
- **多选题**：可多选时使用（"您使用过哪些功能？"）
- **评分题**：5 级李克特量表（满意度）
- **文本题**：
  - 单行：用于简短反馈
  - 多行：用于开放式建议（建议留 3-5 行空间）
- **必填项**：必填的题目打开"必填"开关

### 2.5 设置权限与外观

1. 问卷设置 → 权限：
   - ✅ 允许匿名填写
   - ✅ 每人只能填写一次（防刷）
   - ✅ 显示提交成功页
2. 外观（可选）：
   - 主题色：绿色（与软件主题一致）
   - 封面图：可放软件截图

### 2.6 发布问卷

1. 点击右上角 **"发布"** 按钮
2. 选择发布渠道：
   - **公开链接**：任何人可填（推荐用于比赛展示）
   - **指定人群**：仅限飞书组织内
3. 复制公开链接，格式类似：
   ```
   https://www.feishu.cn/forms/xxxxxxxxxxxxx
   ```
   或
   ```
   https://feishu.cn/forms/xxxxxxxxxxxxx
   ```

### 2.7 嵌入软件

1. 拿到飞书问卷 URL
2. 打开 [about-settings.constants.ts](../../src/renderer/src/pages/about-settings.constants.ts)
3. 替换占位符：
   ```typescript
   // 修改前
   export const FEISHU_FEEDBACK_URL = 'https://www.feishu.cn/forms/PLACEHOLDER_REPLACE_ME'

   // 修改后
   export const FEISHU_FEEDBACK_URL = 'https://www.feishu.cn/forms/你的实际ID'
   ```
4. 保存后软件"设置 → 关于 → 产品调研问卷"卡片自动跳转新链接

### 2.8 验证

1. 启动应用：进入 **设置 → 关于**
2. 找到"产品调研问卷"卡片，点击
3. 应能正常打开飞书问卷页面
4. 提交一个测试答案，确认飞书后台能收到

## 3. 问卷优化建议

### 3.1 题目顺序原则

- **简单 → 复杂**：先问背景（选择题），再问体验（评分），最后开放式
- **正向 → 负向**：先问满意的地方，再问改进点
- **总时长控制**：2-3 分钟最理想，8-12 题

### 3.2 比赛场景特殊考虑

- 在问卷描述里加一句：**"感谢参与火山杯 2026 比赛评审，您的反馈对我们至关重要"**
- 提交后可显示：**"感谢您的反馈！比赛期间每个建议我们都会认真查看"**
- 数据导出：飞书问卷支持 Excel 导出，比赛结束后可快速整理为复盘材料

### 3.3 数据隐私

- 飞书问卷默认存储在飞书云端，中国大陆境内
- 不收集 IP / 设备指纹（除非开启高级分析）
- 开源项目无需担心 GDPR（仅服务国内用户）

## 4. 常见问题

**Q1：飞书问卷要收费吗？**
A：免费版支持 1000 条/月的填写量，火山杯比赛期间完全够用。

**Q2：能不能直接用 Google Form？**
A：可以，但国内访问 Google 不稳定。飞书是国内首选，访问速度 + 集成度更好。

**Q3：链接被微信/QQ 屏蔽怎么办？**
A：飞书域名 `feishu.cn` 一般不会被屏蔽，但可以用短链（bit.ly）兜底。

**Q4：问卷收集的数据怎么用？**
A：导出 Excel → 分类整理 → 作为比赛交付材料的"用户反馈"章节佐证。
