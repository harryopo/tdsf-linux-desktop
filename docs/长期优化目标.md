## 零 · 先说清过去为什么排期全落空

ROADMAP 顶部写着「带日期的版本号没有一条按时间表落地过」。回代码看，原因不是估时不准，是三个结构性问题：

1. **能力按通道横向铺，没有一条从「通道存在」到「界面真的调用它」的闭环判据。**
   结果是 preload 暴露 274 个键、**139 个渲染层零引用**（2026-10-21 实测；10-20 记 141，本轮把
   `storageDeleteApiKey` 接到界面、并把上一批遗漏未降的 `historyBlocks` 一起收进刻度，
   因为那条原先是 INFO 不阻断——现在 `audit:ipc` 里钉了只降不升的刻度）；`audit:ipc` FAIL=0 只保证不断链，不保证有人按。
2. **调研产出了结论，结论没有转成代码里的 skip、闸或 README 的一行。**
   SSH 的 7 条基本功差距（G1–G7）原先只写在本机 reports 目录里那份 2026-10-04 的调研文档，**而那份文档不在仓库里**，
   门禁也不扫它——所以「跳板机不校验主机密钥」标了 P0 之后仍然靠人记得。
3. **所有 ratchet 都定在当天实测值上，于是「全绿」与「零余量」同时成立。**
   `as never` 69/69、旧 `--trae-*` 64/64、内联 style 109/109 —— 三条顶格（knip duplicates 已在 2026-10-20 清零）。
   门只能防回涨，不能推动下降；一动手重构就立刻红，于是重构被推迟。

**因此这份清单的第一原则是：先判决、再下降、最后才加新能力。**

## 五 · 安全欠账（按「能不能被证伪」排序）

- **模型下载无字节校验（2026-10-22 已修）**：下载与校验收口到
  `services/tutorial/embedding-model.ts`——先取字节，比对仓库里钉死的 SHA-256
  （量化 ONNX `15b717c3…`，与上游 lfs.oid 一致），通过后才写进 transformers 缓存；
  `allowRemoteModels=false`，缓存未命中直接报错，不再由 transformers 自行下载。
  判据 `tests/unit/embedding-model-integrity.test.ts`（坏字节 / 错大小 / 错哈希 / HTTP 非 200）
  加一次"只给校验过的缓存、断网加载出 512 维向量"的真机探针。
  **仍未做**：把 24MB 权重打进 `resources/`，所以首次使用仍要联网一次。
  下面是 2026-10-20 取证到的三条约束，留作后续改动的背景：
  ① 哈希**不能运行时向同一主机要**——让下载源同时提供文件和自己的哈希等于没有校验。
  （2026-10-22 实测本机直连两个源都超时；官方源经代理可达。下载顺序是
  `hf-mirror.com` → `huggingface.co`，任一源返回的字节都要过同一张钉死的哈希表。）
  所以值必须**钉进仓库**（`GET https://hf-mirror.com/api/models/{id}/tree/main?recursive=true`
  的 `lfs.oid` 就是 64 位十六进制 SHA-256，取一次人工核对后入库，并配一条刷新脚本 + "上游换了 revision 就拒加载"的说明）。
  ② 非 LFS 的小文件（`config.json` / `tokenizer.json` / `vocab.txt`）那份 API 只给 git blob SHA-1（40 位），
  要按 SHA-1 验 git blob 算法（`sha1("blob <len>\0" + 内容)`），别当 SHA-256 用。
  ③ 挂载点：装的 `@xenova/transformers` 的 `src/utils/hub.js` **没有 `customFetch`**（grep 0 命中），
  拦不了 fetch；可行落点是它自己的缓存目录——`embedding-service.ts:275` 已把 `env.cacheDir` 设成
  `userData/models`，而缓存键就是 `Xenova/bge-small-zh-v1.5/<相对文件路径>`（`hub.js:391,405`）。
  即：**我们自己取字节、验完再写进那个路径**，`pipeline()` 走缓存命中，未验过的字节不进运行时。
  判据：改一个字节必须拒绝加载（阳性对照），并且现有"能出 512 维向量"那条正向用例仍然过。
- **审批没有「记住这次决策」的能力，也不该有半态**（2026-10-20 收口）：
  `src/main/core/security/approval.ts` 曾导出 `readRemember`，注释写着"remember=true 会被持久化成自动放行规则"，
  而**全仓没有任何界面、IPC 载荷或存储带 `remember` 字段**——它只有自己的单测在调，生产零调用者。
