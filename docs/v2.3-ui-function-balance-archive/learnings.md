## LRN-20260723-001 · 大文件拆分应以质量为导向

**背景**：用户明确反馈"不要为了拆分大文件而拆分"，要求保证质量优先。
**结论**：
- 行数本身不是缺陷
- 只有当大文件导致职责混杂、重复代码、测试困难、性能下降时才拆分
- 结构清晰的大文件可以保留
**关联修改**：CLAUDE.md v2.5 B1 + AGENTS.md v8.7 第 2 节

## LRN-20260723-002 · Phase T/U 并行实施的文件隔离

**背景**：Phase T 和 Phase U 由不同 subagent 实施，但共享同一渲染层代码库。
**结论**：
- 父 agent 按功能域串行派发（先 T 后 U），避免同一文件并发修改
- 每个 subagent 完成后立即跑编译门禁，问题早发现早修复
- 最终父 agent 统一跑三绿验证作为兜底

## LRN-20260723-003 · 历史页面时间筛选的前端兜底策略

**背景**：HistoryPage 后端未提供时间范围查询参数。
**方案**：前端按 timestamp 过滤 historyData，保留现有分页/搜索逻辑。
**优点**：零后端改动，用户可感知功能立即生效。

## LRN-20260723-004 · AboutSettings 真实应用信息的最小 IPC 设计

**背景**：需要展示真实版本号、构建时间、安装路径。
**方案**：新增 `app:get-info` IPC，主进程返回 3 个字段，渲染层失败时回退到本地常量。
**原则**：IPC 通道最小化，避免过度设计。

---

## LRN-20260723-005 · 空状态组件统一替换

**背景**：多个页面空状态使用简单文本或硬编码样式。
**方案**：统一使用项目内 `<Empty>` 组件，保持视觉一致。
**收益**：减少硬编码颜色，提升可维护性。
