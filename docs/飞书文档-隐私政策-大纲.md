## 1. 引言

**TDSF Linux**（以下简称"本软件"或"我们"）是一款面向 Linux 运维教学的桌面应用。我们非常重视您的隐私（privacy），本政策说明我们如何收集、使用、存储和保护您的信息。

> **承诺（Our Commitment）**：
> - ✅ 默认本地优先（Local-First by default）
> - ✅ 敏感文件自动脱敏（Auto-redact sensitive files）
> - ✅ 所有网络请求 UI 可见（All network requests UI-visible）
> - ✅ 不上传 SSH 凭据（Never upload SSH credentials）
> - ✅ 不出售用户数据（Never sell user data）

**适用对象**（Applicable to）：本软件 v2.4.1 及以上版本的所有用户。

## 2. 数据收集范围

### 2.1 本地存储数据（Local Storage，100% 不上传）

以下数据**仅存储在您的本地设备**（stored locally only），不会上传到任何服务器：

| 数据类型 | 存储位置 | 用途 | 是否加密 |
| --- | --- | --- | --- |
| SSH 连接配置 | SQLite（better-sqlite3） | 连接管理 | 否（不含密码） |
| SSH 密码 / 私钥 | safeStorage（OS 钥匙串） | 认证 | ✅ 是（DPAPI/Keychain） |
| 终端历史 | SQLite | 翻阅历史 | 否 |
| 决策历史 | SQLite | 审计追溯 | 否 |
| 知识库数据 | SQLite + 向量索引 | 知识检索 | 否 |
| 用户偏好设置 | electron-store | 个性化 | 否 |

### 2.2 LLM 调用数据（LLM Call Data，**可选上传**）

当您使用 AI 助手功能时，您的提问和上下文可能被发送给 LLM 提供商：

| 数据 | 是否发送 | 默认行为 | 用户可控 |
| --- | --- | --- | --- |
| 您的提问 | ✅ 是 | 必发 | ❌ 否（功能依赖） |
| 服务器名称 / IP | ✅ 是 | 必发 | ❌ 否（功能依赖） |
| 命令输出 | ✅ 是 | 必发 | ❌ 否（功能依赖） |
| 文件内容 | ⚠️ 可选 | 默认 redact | ✅ 是（设置可关） |
| SSH 密码 | ❌ 否 | 自动 redact | — |
| 私钥内容 | ❌ 否 | 自动 redact | — |
| API Key | ❌ 否 | 自动 redact | — |
| `.env` 文件 | ❌ 否 | 自动 redact | — |
| `~/.ssh/` 目录 | ❌ 否 | 自动 redact | — |
| `*_key` / `*_token` | ❌ 否 | 自动 redact | — |

### 2.3 不收集的数据（What We DO NOT Collect）

- ❌ 不收集 SSH 密码 / 私钥内容
- ❌ 不收集 API Key / Token
- ❌ 不收集 .env / credentials.json
- ❌ 不收集 ~\.ssh\ 目录文件
- ❌ 不收集浏览器 Cookie / 历史
- ❌ 不收集系统其他文件
- ❌ 不收集个人身份信息（PII）用于商业目的
- ❌ 不向第三方出售任何数据

## 3. 数据存储与加密

### 3.1 加密标准

| 存储项 | 加密方式 | 平台实现 |
| --- | --- | --- |
| SSH 密码 | safeStorage | Windows: DPAPI（Data Protection API）<br>macOS: Keychain<br>Linux: libsecret/kwallet |
| SSH 私钥 | safeStorage | 同上 |
| LLM API Key | safeStorage | 同上 |
| 用户偏好 | electron-store | 明文 JSON（本地） |
| 业务数据 | better-sqlite3 | 明文 SQLite（本地） |

### 3.2 数据位置

- **Windows**：`%APPDATA%\tdsf-linux-desktop\`
- **macOS**：`~/Library/Application Support/tdsf-linux-desktop/`
- **Linux**：`~/.config/tdsf-linux-desktop/`

### 3.3 数据保留期

| 数据 | 保留期 | 清理方式 |
| --- | --- | --- |
| SSH 连接配置 | 永久（直到用户删除） | 手动删除 |
| 终端历史 | 90 天 | 自动滚动 |
| 决策历史 | 永久 | 手动删除 |
| LLM trace | 30 天 | 自动清理（本地） |

### 3.4 卸载时清理

卸载 TDSF Linux 时，**所有本地数据将被自动删除**。
如需保留某些数据，请提前备份 `%APPDATA%\tdsf-linux-desktop\` 目录。

## 4. LLM 调用与数据上传

### 4.1 LLM Provider 配置

本软件支持以下 LLM Provider（**用户自配**，我们不提供默认 Key）：

| Provider | 端点 | 隐私政策 |
| --- | --- | --- |
| 火山方舟（Volcano Ark） | `https://ark.cn-beijing.volces.com/api/v3/` | [查看](https://www.volcengine.com/docs/6257/68912) |
| OpenAI | `https://api.openai.com/v1/` | [查看](https://openai.com/policies/privacy-policy) |
| Anthropic Claude | `https://api.anthropic.com/` | [查看](https://www.anthropic.com/privacy) |
| 自定义（Custom） | 用户配置 | 取决于服务方 |

### 4.2 数据流（Data Flow）

```
┌──────────────┐         ┌──────────────┐         ┌──────────────┐
│  本地问题    │ ──────> │  Redact 引擎 │ ──────> │  LLM Provider│
│  + 上下文    │ redact │  (本地处理)  │ 发送   │  (火山/OpenAI)│
└──────────────┘         └──────────────┘         └──────────────┘
                              │                          │
                              │ 过滤:                    │
                              │ - .env                   │
                              │ - .ssh/                  │
                              │ - *_key                  │
                              │ - *_token                │
                              ▼                          ▼
                         安全数据                  接收响应
```

### 4.3 Langfuse 可观测性（可选）

如果您配置了 Langfuse（用于 LLM trace 追踪），LLM 调用元数据可能上传至：
- **自部署 Langfuse**（推荐）：完全本地控制
- **Langfuse Cloud**：受 Langfuse 隐私政策约束

**默认关闭**（Default: OFF）。如需开启，请进入 **设置 → 可观测性** 手动配置。

### 4.4 提示注入防护（Prompt Injection Defense）

- 所有 LLM 输出必须经过 **Ground-Check** 证据验证
- 工具调用必须经过 **4 层风险控制**
- 敏感路径操作强制 **人工审批（Human-in-the-Loop）**

## 5. 网络请求白名单

### 5.1 默认允许的网络请求

| 域名 | 用途 | 是否必须 |
| --- | --- | --- |
| `https://ark.cn-beijing.volces.com/*` | LLM API（火山方舟） | 配置后 |
| `https://api.openai.com/*` | LLM API（OpenAI） | 配置后 |
| `https://api.anthropic.com/*` | LLM API（Anthropic） | 配置后 |
| `https://github.com/*` | 更新检查、Issue 反馈 | 可选 |
| `https://pypi.org/*` | 教学资源下载 | 可选 |

### 5.2 网络请求可见性

**所有出站网络请求必须在 UI 可见**（参考 Grok Build 数据丑闻教训）：
- LLM 调用：在 Chat Panel 显示 token 数 + 延迟
- 下载任务：在 Monitor Panel 显示进度
- 任何请求：可在 **设置 → 网络日志** 查看

### 5.3 网络隔离（Network Isolation）

- 默认无网络请求（无 LLM 配置时）
- 离线模式：所有网络请求禁用
- 沙箱模式：危险操作在隔离环境执行

## 7. 用户权利

您对自己的数据拥有以下权利：

### 7.1 访问权（Right to Access）
- 查看所有本地存储数据：进入 **设置 → 数据管理 → 导出**
- 查看所有 LLM 调用历史：进入 **设置 → 隐私 → 调用日志**

### 7.2 更正权（Right to Rectification）
- 修改 SSH 连接配置：连接管理页面
- 修改偏好设置：设置页面
- 修改 API Key：模型设置页面

### 7.3 删除权（Right to Erasure / "Right to be Forgotten"）
- **删除单条 SSH 连接**：连接列表 → 右键 → 删除
- **清空终端历史**：设置 → 隐私 → 清空历史
- **清空决策历史**：设置 → 隐私 → 清空决策
- **完全卸载并删除所有数据**：卸载软件即可

### 7.4 数据可移植性（Data Portability）
- 导出所有本地数据：设置 → 数据管理 → 导出（JSON 格式）
- 导出知识库贡献：知识库 → 我的贡献 → 导出

### 7.5 拒绝权（Right to Object）
- 关闭 LLM 调用：移除 API Key
- 关闭 Langfuse：设置 → 可观测性 → 关闭
- 关闭网络：进入离线模式

## 8. 儿童隐私

本软件面向**教学场景**，可能包括未成年用户（高校学生）。

- ❌ 不故意收集 14 岁以下儿童信息
- ✅ 学校 / 教师应在监督下使用
- ✅ 教学场景建议使用匿名化 API Key
- ✅ 决策历史默认仅本地保留

如发现误收集儿童信息，请立即联系我们删除。
