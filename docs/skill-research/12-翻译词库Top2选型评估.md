### 2.5 字段映射到本地 schema

**本地目标 schema**（v1.0 命令补全需要）：
```typescript
interface Command {
  command: string;          // 命令名
  description: string;      // 中文描述（已用 dist.data.json.d）
  pos?: string;            // 词性（n/v/adj） - 需推断
  example?: string;        // 使用示例 - 需从 Markdown 提取
  category: string;        // 分类（文件/网络/系统/权限/压缩/...）
  level: 1 | 2 | 3 | 4;   // 难度等级
  courseChapter?: string;  // 课程章节映射
  detail?: string;         // 详细说明
  syntax?: string;         // 语法
  options?: Array<{        // 选项列表
    flag: string;
    desc: string;
  }>;
}
```

**映射表**：

| 目标字段 | 数据源 | 提取方法 | 难度 |
|---------|--------|---------|------|
| `command` | `dist.data.json[*].n` | 直接使用 | ⭐ |
| `description` | `dist.data.json[*].d` | 直接使用 | ⭐ |
| `pos` | 推断（基于命令类型） | 正则匹配命令名 + 启发式 | ⭐⭐ |
| `example` | `command/{n}.md` 的 `### 实例` 代码块 | Markdown 解析 | ⭐⭐ |
| `category` | 关键词分类（`file/net/sys/perm/...`） | 命令名 + 描述启发式 | ⭐⭐ |
| `level` | 命令复杂度（入门/中级/高级/专家） | 命令名 + 选项数启发式 | ⭐⭐ |
| `courseChapter` | 课程章节映射 | 人工标注 + LLM 辅助 | ⭐⭐⭐ |
| `detail` | `command/{n}.md` 的 `## 补充说明` 段 | Markdown 解析 | ⭐⭐ |
| `syntax` | `command/{n}.md` 的 `### 语法` 代码块 | Markdown 解析 | ⭐⭐ |
| `options` | `command/{n}.md` 的 `### 选项` 代码块 | 正则解析 | ⭐⭐⭐ |

**实施建议**：
- **Phase 0**：仅用 `dist/data.json` → `{command, description}` 2 字段（最快，1 天）
- **Phase 1**：解析 Markdown 源文件，补齐 `detail/syntax/options/examples` 4 字段（3 天）
- **Phase 2**：用 LLM 批量补齐 `pos/category/level/courseChapter` 4 字段（5 天）

### 3.2 pages.zh/common/ls.md Schema

**实际样本**（从 GitHub API 抓取）：

```markdown
# ls

> 列出目录中的内容。
> 更多信息：<https://www.gnu.org/software/coreutils/manual/html_node/ls-invocation.html>。

- 列出目录中的文件，每个文件占一行：

`ls -1`

- 列出包含隐藏文件的所有文件：

`ls {{[-a|--all]}}`

- 列出所有文件，如果是目录，则在目录名后面加上「/」：

`ls {{[-F|--classify]}}`

- 列出包含隐藏文件的所有文件信息，包括权限，所有者，大小和修改日期：

`ls {{[-la|-l --all]}}`

- 列出所有文件信息，大小用人类可读的单位表示（KiB, MiB, GiB）：

`ls {{[-lh|-l --human-readable]}}`

- 列出所有文件信息，按大小降序排序：

`ls {{[-lSR|-lS --recursive]}}`

- 列出所有文件信息，按修改日期从旧到新排序：

`ls {{[-ltr|-lt --reverse]}}`

- 只列出目录：

`ls {{[-d|--directory]}} */`
```

### 3.3 pages.zh/common/tar.md Schema

**实际样本**：

```markdown
# tar

> 归档实用程序。
> 通常与压缩方法结合使用，例如 `gzip` 或 `bzip2`。
> 更多信息：<https://www.gnu.org/software/tar/manual/tar.html>。

- 创建存档并将其写入文件：

`tar cf {{目标文件.tar}} {{路径/到/文件1 路径/到/文件2 ...}}`

- 创建一个 gzip 压缩文件并将其写入文件：

`tar czf {{目标文件.tar.gz}} {{路径/到/文件1 路径/到/文件2 ...}}`

- 使用相对路径从目录创建一个 gzip 压缩文件：

`tar czf {{目标文件.tar.gz}} {{[-C|--directory]}} {{路径/到/目录}} .`

- 详细地将（压缩的）存档文件提取到当前目录中：

`tar xvf {{源文件.tar[.gz|.bz2|.xz]}}`

- 将（压缩的）存档文件解压缩到目标目录中：

`tar xf {{源文件.tar[.gz|.bz2|.xz]}} {{[-C|--directory]}} {{目标目录}}`

- 创建压缩存档并将其写入文件，使用文件扩展名自动确定压缩程序：

`tar caf {{目标文件.tar.xz}} {{路径/到/文件1 路径/到/文件2 ...}}`

- 详细列出 tar 文件的内容：

`tar tvf {{源文件.tar}}`

- 从存档文件中提取与模式匹配的文件：

`tar xf {{源文件.tar}} --wildcards "{{*.html}}"`
```

## 四、字段映射统一表

### 4.1 合并去重策略

| 数据源 | 主键 | 去重依据 |
|--------|------|---------|
| jaywcjlove/linux-command | `command` (n) | 命令名（去重单位） |
| tldr-pages/tldr (zh) | 文件名（ls.md） | 命令名（去重单位） |

**合并优先级**：
1. 命令名相同 → 保留两者，**jaywcjlove 提供 description**，**tldr 提供 examples**
2. 仅 jaywcjlove 有 → 直接入库
3. 仅 tldr 有 → 翻译 description（如有英文版）
4. 都不全 → 标记为待补全

### 4.2 统一 schema

```typescript
interface LinuxCommand {
  // 基础字段（Phase 0 必须）
  command: string;              // 命令名（"ls"）
  description: string;          // 中文描述（一句话）
  
  // 来源标记（Phase 0 必须）
  sources: Array<'jaywcjlove' | 'tldr-zh' | 'manual'>;
  jaywcjlove_path?: string;     // `/ls`
  tldr_path?: string;           // `pages.zh/common/ls.md`
  
  // 增强字段（Phase 1 可选）
  detail?: string;              // 详细说明
  syntax?: string;              // 语法
  options?: Array<{
    flag: string;               // "-R" 或 "--recursive"
    desc: string;               // "递归列出..."
  }>;
  examples?: Array<{
    desc: string;               // "列出详细信息"
    code: string;               // "ls -l"
  }>;
  reference?: string;           // "https://..."
  
  // 分类字段（Phase 2 LLM 标注）
  pos?: 'n' | 'v' | 'adj';     // 词性
  category?: 'file' | 'network' | 'system' | 'permission' | 'compress' | 'process' | 'text' | 'disk' | 'other';
  level?: 1 | 2 | 3 | 4;       // 1=入门 2=中级 3=高级 4=专家
  courseChapter?: string;      // "第3章-文件操作"
  
  // 元数据
  license: 'MIT' | 'CC-BY-4.0';
  last_updated: string;         // ISO date
}
```
