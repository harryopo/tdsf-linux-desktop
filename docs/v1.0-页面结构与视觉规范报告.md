## 一、整体布局结构

### 1.1 全局根元素

所有页面统一使用以下根元素结构：

```html
<!DOCTYPE html>
<html lang="zh-CN" class="dark">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>{页面名} - TDSF</title>
  <style id="theme-vars">… TRAE tokens …</style>
  <script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4.3.1/dist/index.global.js"></script>
  <script src="https://unpkg.com/lucide@1.8.0/dist/umd/lucide.min.js"></script>
  <style type="text/tailwindcss">@theme inline {…} @layer base {…}</style>
  <style id="semantic-token-fallback">… bg-card / text-foreground 等语义类 …</style>
  <style id="global-focus-visible">… :focus-visible 蓝色描边 …</style>
  <style id="brand-override">… 品牌色 #32F08C → #387BFF 覆盖 …</style>
  <style id="component-vars">… ds-* 组件定义 …</style>
  <style id="page-vars">… 页面级 CSS …</style>
</head>
<body class="min-h-screen font-sans antialiased">
  <main>…</main>
</body>
</html>
```

### 1.2 三种布局模式

| 布局模式 | 适用页面 | 关键特征 |
|---|---|---|
| **三栏式工作台** | `workbench-ai.html` | 左侧 Activity Rail(48px) + 中央工作区 + 右侧 AI 面板(可折叠) |
| **两栏式设置页** | `settings.html`、`settings-general/appearance/model/risk/ssh/terminal/decision.html` | 左侧导航(220px) + 右侧 panel，顶栏含返回按钮 + 标题 + 副标题 |
| **单栏内容页** | `boot/monitor/history/history-detail/knowledge/knowledge-detail/decision-detail/tutorial/tutorial-detail/logs/settings-about.html` | 顶部 PageHeader + 主体内容区（含 section 分块） |

- `--bg-layout-1: var(--bg-base-secondary)` —— 一级布局背景

## 六、图标系统

### 6.1 图标库

使用 **Lucide 1.8.0** UMD 版本：`https://unpkg.com/lucide@1.8.0/dist/umd/lucide.min.js`

### 6.2 图标渲染技术：CSS Mask

所有图标统一使用 `[data-icon]` 属性 + CSS mask 技术，将 SVG 作为 mask 图案，颜色由 `currentColor` 控制：

```css
[data-icon] {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  -webkit-mask-size: contain;
  mask-size: contain;
  -webkit-mask-repeat: no-repeat;
  mask-repeat: no-repeat;
  -webkit-mask-position: center;
  mask-position: center;
  background-color: currentColor;
}
```

### 6.3 图标尺寸工具类

`.di-12 (12×12)` / `.di-14 (14×14)` / `.di-16 (16×16)` / `.di-18 (18×18)` / `.di-20 (20×20)`

### 6.4 图标路径

统一存放在 `../assets/icons/dl_builtin_trae/` 目录，使用方式：

```html
<span data-icon style="width:14px;height:14px;
  -webkit-mask-image:url('../assets/icons/dl_builtin_trae/arrow-left.svg');
  mask-image:url('../assets/icons/dl_builtin_trae/arrow-left.svg');
```

## 十二、视觉效果总结

### 12.1 整体视觉语言

**Geek Hard-edged Dark Theme** —— 极客硬边暗色主题，源自 Trae Design Library。

**核心特征**：

1. **纯暗色背景**：`#1A1B1D` 画布 + `#222427` 卡片，无亮色变体（`<html class="dark">`）
2. **硬边圆角**：圆角值小（4/6/8/10），不追求圆润感，按钮 radius 仅 4px
3. **单层阴影**：仅 `0 1px 3px rgba(0,0,0,0.3)`，无多层柔和阴影
4. **高对比文字**：`#D1D3DB` 默认 + `#F5F9FE` hover，文字层级清晰
5. **品牌色覆盖**：原绿色 `#32F08C` 被项目蓝色 `#387BFF` 覆盖，但保留所有语义状态色
6. **等宽数字**：所有数字使用 `tabular-nums` + `lnum`，对齐工整

### 12.2 信息密度

- **decision-detail.html** 采用 **Density Override** 收紧排版（spacer-16=12px / body-base=11px / heading-md=20px），单页承载 7 个区域仍保持紧凑
- **settings-model.html** 采用 **KPI + 多 section** 模式，4 个 KPI 卡 + 6 个 section，每 section 含子组件
- **settings 全系列** 采用 **两栏 + 卡片堆叠** 模式，左侧 220px 导航 + 右侧 4-5 张 ds-card 垂直排列

### 12.3 数据可视化风格

- **SVG 直接绘制**：所有图表（折线、雷达、仪表、六边形、sparkline）均使用 SVG 直接绘制，不依赖 Chart.js / D3
- **品牌色为主**：图表主色用 `var(--bg-brand)`，辅色用 `--brand-3`（虚线）或 `--status-success-default`
- **低饱和填充**：填充透明度 0.08-0.18，避免抢眼
- **网格线极淡**：`var(--bg-overlay-l2)` 网格线，1px 描边

### 12.4 字体策略

- **正文**：`SF Pro Text` + `Microsoft YaHei` fallback，11-13px 紧凑字号
- **标题**：`SF Pro` 字重 600，最大 28px（heading-2xl）
- **代码/数字**：`JetBrains Mono` 450 字重（介于 regular 和 medium 之间），所有数字 tabular-nums

### 12.5 三种 token 系统变体

| 变体 | 使用页面 | 特征 |
|---|---|---|
| **完整 TRAE token** | decision-detail / settings-model / history-detail / logs / knowledge / tutorial 等 | 300+ token，含 brand-green 1000 / brand-red 1000 等完整色阶 + viz 系列 + risk 别名 |
| **标准 TRAE token + trae- 前缀别名** | settings-general / appearance / risk / ssh / decision / about | 标准 token + `--trae-*` 前缀别名供 `@theme inline` 桥接 |
| **简化 token 系统** | settings-terminal | 约 100 token，无 trae- 前缀，品牌色直接在 :root 定义，spacer 使用 1-8 简化命名 |

### 12.6 品牌色覆盖三种方式

1. **:root 内直接重定义**（settings-terminal / settings-model）：在 `:root` 内直接覆盖 `--bg-brand: #387BFF` 等变量
2. **body 内 `<style id="brand-override">` 标签覆盖**（settings.html 系列、decision-detail）：在 body 起始处插入 style 标签覆盖
3. **不覆盖**（保留原绿色）：仅 `boot.html` 等极少数页面保留 `#32F08C`

### 12.7 一致性评分

| 维度 | 评分 | 说明 |
|---|---|---|
| 配色一致性 | 9/10 | 品牌色统一覆盖为 #387BFF，状态色保留 TRAE 原值 |
| 字体一致性 | 10/10 | 全站统一 SF Pro Text + JetBrains Mono |
| 间距一致性 | 8/10 | 标准页面用 spacer-4/6/8/12/16/24/32/40，terminal 用 1-8 简化版，decision-detail 用 Density Override |
| 圆角一致性 | 9/10 | 4/6/8/10/full 五级清晰，组件用法统一 |
| 组件一致性 | 9/10 | ds-* 前缀组件库覆盖 23 个组件，仅 about 用 ab-* 前缀 |
| 图标一致性 | 10/10 | 统一 Lucide 1.8.0 + CSS mask 技术 |
| 动画一致性 | 9/10 | 全站支持 prefers-reduced-motion，曲线统一 cubic-bezier(.3,0,0,1) |
| 交互一致性 | 9/10 | data-dom-id 标注规范，CSS-only 交互模式复用度高 |

### 12.8 设计亮点

1. **D-S 证据理论透明化**：decision-detail.html 将六源证据权重可视化（雷达图 + 进度条 + 数字），符合可解释 AI 要求
2. **命令语法 5 色高亮**：cmd-name/flag/path/val/sym 五色高亮，运维场景可读性极强
3. **高危命令拦截清单**：CSS-only 折叠展开 + 左侧色条（红/橙）+ 拦截状态徽章
4. **KPI 卡 + mini sparkline**：settings-model 用 4 张 KPI 卡 + 24px 高 SVG sparkline 展示趋势，紧凑高效
5. **置信度仪表**：220×220 SVG 多段弧 + 中心数字 + 6 源权重明细，单页视觉锚点
6. **流光路径 + 脉冲节点**：decision-detail 用 `stroke-dashoffset` 动画 + `box-shadow` 脉冲表达"决策流动"
7. **Terminal 三色点**：红黄绿三色点（status-error/alert/success）作为终端装饰，呼应 macOS 终端
8. **Inline SVG 内联**：knowledge-detail 大量使用 data-uri 内联 SVG，避免外部图标依赖

### 12.9 改进建议

1. **统一品牌色覆盖方式**：建议统一为 `:root` 内直接重定义，去除 `<style id="brand-override">` 标签覆盖方式，减少 DOM 节点
2. **统一 spacer 命名**：settings-terminal 的 1-8 命名应迁移到标准 4/6/8/12/16/24/32/40 命名
3. **ab-* 组件归一化**：settings-about 的 ab-* 前缀应迁移到 ds-* 前缀，保持组件库单一
4. **图表库抽象**：建议将 SVG 折线/雷达/仪表抽取为独立组件（如 `.ds-chart-line` / `.ds-chart-radar` / `.ds-chart-gauge`），复用到其他页面
5. **内联样式迁移**：decision-detail 和 settings-model 大量使用 inline style，建议迁移到 page-level CSS class，提升可维护性
6. **响应式补全**：部分页面（如 settings-about）未设置响应式断点，建议补充 `sm/md/lg` 适配
