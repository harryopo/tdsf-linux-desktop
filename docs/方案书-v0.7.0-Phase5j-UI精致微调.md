## 0. 写作原则（务必先读）

> 美化是一种**整体的感觉**，恰到好处，多了也不好，少了也不好。
> **本方案不做大刀阔斧的样式重写，只做"看起来对了"的微调。**

| 原则 | 含义 |
|------|------|
| **不动变量** | 不修改 `--color-*` `--font-size-*` `--space-*` `--radius-*` token 体系 |
| **不破坏 φ** | 所有改动必须仍能追溯到黄金比例推导 |
| **不引入新依赖** | 不引入新组件库、新动画库 |
| **禁止 emoji** | 一致性硬规范 |
| **CSS 变量必须用 `var(--color-*)`** | 禁止硬编码 `#ffffff` 等 |
| **改动越小越好** | 单条 CSS 改动 ≤ 3 行 |
| **不"为了优化而优化"** | 锦上添花但不必要的改动标注"不建议改" |

## 2. 21st.dev 优秀组件的灵感提炼

### 2.1 ChatGPT / Claude / Trae 风格 — "Rounded Pill Composer"

**调研来源**：
- [21st.dev Ai Chat Input](https://21st.dev/community/components/ruixenui/ai-chat-input/default)
- [Prompt-Area styles](https://prompt-area.com/styles)（ChatGPT/Claude/Codex/Gemini 4 种风格对比）
- [Trae IDE 对话](https://docs.trae.cn/ide_chat)
- [SetProduct AI Chat UI](https://www.setproduct.com/blog/ai-chat-interface-ui-design)

**核心理念**（提炼 3 条）：

#### 灵感 1：胶囊化 + 控件内联

```
┌─────────────────────────────────────────────────────────────┐
│ [+]  [🧠 深度思考]    输入框...           [🎤 语音]  [↑ 发送] │
└─────────────────────────────────────────────────────────────┘
  ↑   ↑                    ↑                     ↑       ↑
  附件 思考开关            textarea            语音      主按钮
```

> **左侧 + 按钮（附件 dropdown）** + **中间 textarea** + **右侧圆按钮**（语音/发送二选一）
> 所有控件在**一个圆角胶囊**内，仿 iMessage / Apple Notes / ChatGPT。
> **比当前设计精进了 2 处**：附件入口（必备）+ 思考开关（差异化亮点）。

#### 灵感 2：语音按钮与发送按钮**互斥**

> 文本为空时 → 显示麦克风
> 文本非空时 → 显示发送箭头
> 录制中 → 麦克风变红色方块（停止）

**应用**：可选，本期**不实现语音**（v0.7.0 暂不接 Web Speech API），**但预留位置**（先放图标 hover 提示"语音（即将支持）"）。

#### 灵感 3：步骤化状态指示

> Claude 风格：每条 AI 消息有"小步骤"，折叠可看（搜索→分析→回答）
> 思考时显示"正在查阅 3 个工具..."带动态省略号

**应用**：当前已有 `chat-message-typing` 显示步骤，可增强为**带步骤图标**（`<CloudSyncOutlined />` 等）的进度条。

### 2.2 监控仪表盘 — Stripe / Vercel / Linear 风格

**调研来源**：
- [AIDesigner Dashboard 2026](https://www.aidesigner.ai/blog/how-to-design-a-dashboard-ui)
- [think.design Dashboard 2026](https://think.design/blog/dashboard-design-in-2026-dos-and-donts/)
- [gummble Mobile Dashboard](https://gummble.com/blog/mobile-dashboard-design-examples)
- [stellae.design Stat component](https://www.stellae.design/en/components/stat)

**核心理念**（提炼 2 条）：

#### 灵感 4：每个 MetricCard 都应有**图标 + sparkline**

```
┌──────────────────────────────┐
│ [📊] CPU            38%      │
│ ───/\───/\───/─              │
└──────────────────────────────┘
   ↑   ↑           ↑   ↑
   图标 label    数字 sparkline
```

> **3 件套 = 图标 + 数字 + sparkline**，扫一眼就知道是什么、现在多少、走势。
> 我们的当前 MetricCard 只有 label + value，**缺图标 + sparkline**。
> 但本期**不引入 sparkline**（需要从 Recharts 引，复杂度高），**只加图标**。

#### 灵感 5：颜色编码 = 状态而非装饰

> 绿/橙/红 = 健康/警告/危险，**只用这三个颜色表示状态**。
> 主色蓝 = 品牌 + 中性指示（不用于状态）。
> 我们的 `--color-risk-safe/low/medium/high/critical` 5 级已经做到，**继续保持**。

### 2.3 Agent 工作流 — Trae / Manus / Devin 风格

**调研来源**：
- [Trae Builder 文档](https://traeide.com/ja/docs/what-is-trae-builder)
- Anthropic Claude Computer Use / OpenAI Operator / Manus 工作流截图

**核心理念**：

#### 灵感 6：每个步骤**单独可点开看详情**（Trae 风格）

> 当前 AgentWorkflowPanel 已用 Popover 实现，但**默认折叠**。
> 改进：让"当前步骤"自动展开（高亮），其他默认折叠。

**应用**：本期**不实现自动展开**（保持现有交互），但**改 `reason` 步骤的图标**（`BulbOutlined` → `ExperimentOutlined`，更学术）。

**Why**：扫一眼看不出"这是 CPU 还是内存"。

```tsx

import {
  DashboardOutlined, DatabaseOutlined, HddOutlined,
  ThunderboltOutlined, ApiOutlined, AppstoreOutlined,
  ClockCircleOutlined,
} from '@ant-design/icons'

// 标签 → 图标映射（与现有 MetricCard 配套使用）
const METRIC_ICONS: Record<string, React.ReactNode> = {
  'CPU': <DashboardOutlined />,
  '内存': <DatabaseOutlined />,
  '磁盘': <HddOutlined />,
  '负载': <ThunderboltOutlined />,
  '网络入': <ApiOutlined />,
  '网络出': <ApiOutlined />,
  '进程数': <AppstoreOutlined />,
  '运行时间': <ClockCircleOutlined />,
}

const MetricCard: React.FC<{
  label: string
  value: string
  warning?: boolean
}> = ({ label, value, warning }) => (
  <div className={`monitor-metric-card ${warning ? 'warning' : ''}`}>
    <div className="monitor-metric-header">
      <span className="monitor-metric-icon">{METRIC_ICONS[label] ?? <DashboardOutlined />}</span>
      <span className="monitor-metric-label">{label}</span>
    </div>
    <span className="monitor-metric-value">{value}</span>
  </div>
)
```

```css

  color: var(--color-text-tertiary);
  line-height: 1;
}

  color: var(--color-error);
}
```

> ✅ 改动小：+10 行 CSS、+15 行 TSX
