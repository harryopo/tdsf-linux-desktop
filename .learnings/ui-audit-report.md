# TDSF Linux 运维助手桌面应用 UI 审计报告

> 审查日期：2026-07-22  
> 审查方式：视觉模型对比（Playwright 截图 + 设计稿 HTML）+ 源码审查  
> 应用截图目录：`scripts/browser-check/screenshots-fresh/`  
> 设计稿目录：`d:\ai\linux教学一体\参考资料\前端设计\pages\`  
> 对比图目录：`scripts/browser-check/visual-audit-temp/`

---

## 1. 审查概述

本次审查覆盖 TDSF Linux 运维助手桌面应用的全部 19 个可视页面/模块，包括启动页、工作台、运维教程、实时监控、历史决策、运维知识库、系统日志、7 个设置子页以及 4 个详情页。审查结论如下：

| 维度 | 结果 |
|------|------|
| 整体视觉还原度 | 中高（骨架与布局基本一致，但大量细节控件、图标、间距、色彩仍需打磨） |
| 交互完成度 | 中（核心导航与基础点击可用，但多处按钮为占位/提示未实现，若干关键交互缺失） |
| 死 UI / 未实现功能 | 较多（全局搜索、布局切换、终端选中文本翻译、AI 深度分析等仍为占位状态） |
| 设计稿滞后项 | 1 项（实时监控 KPI 展示方式已按新需求改为迷你折线，设计稿仍为环形图） |

### 总体问题分布

| 优先级 | 数量 | 说明 |
|--------|------|------|
| P0（必须立即修复） | 5 | 视觉严重走样或功能完全不可用 |
| P1（影响设计还原） | 21 | 控件样式、布局、间距、图标明显不一致 |
| P2（细节打磨） | 18 | 颜色、字号、hover 状态、对齐等微调 |
| P3（体验增强） | 8 | 动画、滚动条、辅助说明等优化 |

## 2. 全局/跨页面问题

以下问题在多个页面重复出现，建议优先统一修复。

| 优先级 | 问题 | 现状 | 设计稿期望 | 影响页面 | 修复建议 |
|--------|------|------|------------|----------|----------|
| P1 | 图标系统未统一为设计稿自定义 SVG | 大量使用 Lucide 图标（如 `LayoutGrid`、`ArrowLeft`、`Search`、`Settings`） | 应使用 `dl_builtin_trae` 图标库的 mask-image SVG（home、scroll-text、shield、dashboard、layers、clock、file-text、settings、layout、terminal、copy、play 等） | 工作台、所有页面顶部返回按钮、设置页 | 建立图标映射表，将关键图标替换为设计稿 assets 中的对应 SVG |
| P1 | 顶部标题栏返回按钮样式不一致 | APP 使用 `ArrowLeft + 返回工作台` 或 `ArrowLeft + 返回` | 设计稿使用自定义返回图标 + `返回` / `返回设置` 文字，按钮高度 26-28px，边框颜色 `--border-neutral-l2` | tutorial、monitor、history、knowledge、logs、各 settings 子页 | 统一返回按钮组件，使用设计稿图标与尺寸 |
| P1 | 页面标题副标题位置/字号不一致 | 部分页面副标题与标题间距过大或过小 | 标题与副标题应紧凑排列，副标题使用 `--body-xs` / `--text-tertiary` | tutorial、history、knowledge、settings | 统一 `PageHeader` 组件的行高与间距 |
| P2 | 滚动条样式未统一 | 各滚动区域使用浏览器默认滚动条，部分区域未隐藏 | 设计稿中启动页、ActivityRail、横向标签栏等区域应隐藏滚动条 | 全局 | 统一添加 `no-scrollbar` 或自定义滚动条样式 |
| P2 | 卡片阴影/边框 hover 状态不一致 | 部分卡片 hover 同时改变 border + 背景，或无任何反馈 | 设计稿要求卡片 hover 仅改变阴影，禁止同时变 border + 位移 + scale | monitor、knowledge、history | 统一卡片 hover 为单一阴影变化 |
| P2 | 输入框聚焦状态 glow 效果不一致 | 部分输入框聚焦有蓝色 glow，部分仅变 border | 设计稿要求输入框聚焦仅 border 变蓝，无 glow | settings、logs、workbench | 移除 glow，统一 border 颜色变化 |
| P2 | 标签/徽章颜色 token 不统一 | 部分标签使用硬编码或近似色 | 应严格使用 `--trae-bg-brand-popup` / `--trae-text-brand` 等品牌 token | 所有页面 | 全局审查 badge/tag 组件 |
| P3 | 字体族未严格按设计稿 | 当前主要使用系统回退字体 | 设计稿要求 `SF Pro Text` / `SF Pro` / `JetBrains Mono` | 全局 | 确保 Google Fonts CDN 或本地字体正确加载 |

**整体匹配度：中低**

| 优先级 | 问题 | 现状 | 设计稿期望 | 修复建议 |
