## 总体结论

1. **Settings 系列页面存在系统性设计稿滞后问题**：所有设置页（general/model/appearance/risk/ssh/terminal/decision/about）的左侧侧边栏项集合、顺序、激活态均与实际页面不一致，且实际页面大量新增区域（通知、Token 统计、代码高亮主题、应急响应、SSH 安全设置、高级终端、审批通知等）在设计稿中完全缺失。建议优先对齐 Settings 的设计稿或冻结未设计功能。

2. **内容型页面数据不一致**：Tutorial、Tutorial-detail、Knowledge-detail、History-detail、Decision-detail 中存在大量内容/进度/数据差异，部分为测试数据不同导致，需在统一数据基准后重新对比。

3. **Workbench/Monitor 等高频页细节偏差较多**：主要集中于 AI 面板标题栏、时间范围控件、图表网格线、进程监控高度等，需要针对性 CSS 调整。

4. **Boot/Logs 相似度最高**：主要差异为交互状态与少量按钮文案/图标，修复成本较低。

---

## 下一步建议

1. 召开设计-产品对齐会，确认 Settings 侧边栏最终顺序与项集合。
2. 为所有“实际页面有、设计稿无”的功能区域补充设计稿，或从实际页面移除未验收功能。
3. 统一测试数据集，确保内容型页面（教程、知识、历史、决策）截图时使用相同数据。
4. 对高优先级 P0/P1 问题建立修复任务，优先处理侧边栏、图标、布局骨架类问题，再处理间距/字体/颜色微调。
