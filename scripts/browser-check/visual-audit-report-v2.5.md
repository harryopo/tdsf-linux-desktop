## 共性问题与修复方向

1. **左侧设置边栏不一致**
   - 部分设计稿无侧边栏（model、about），实际页面保留；决策控制页面实际边栏缺少入口。
   - 建议：统一所有设置页布局，明确是否保留全局左侧边栏，并补全缺失入口。

2. **标题区图标规范不统一**
   - 大量实际页面在标题左侧新增了返回/页面图标，而设计稿无。
   - 建议：制定全局标题图标规范，要么全部补图标，要么全部按设计稿去除。

3. **新增功能未同步设计稿**
   - 通知设置、API 测试、Token 统计、审计日志、应急响应、安全设置、敏感目录保护、告警通知、执行结果等新增模块导致视觉差异。
   - 建议：将新增功能按设计系统重新设计占位，避免直接堆叠。

4. **数据/状态默认值不同**
   - 统计数字、课程进度、决策编号、开关默认状态、字体大小、行高等不一致。
   - 建议：建立设计 Token 与默认状态表，确保各页面使用统一默认值。

5. **按钮文案与样式不统一**
   - “AI 搜索”vs“AI 检索”、“标记完成”vs“标记已完成”、“模拟执行”vs“采纳执行”、文字按钮 vs 图标按钮等。
   - 建议：统一按钮文案与图标规范。
